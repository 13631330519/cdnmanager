API 接入说明

URL 刷新与文件上传外部接口接入文档，登录后可直接参考。

公共说明：API_Key 获取

本文中的两类接口均使用同一套签名鉴权方式，优先使用“域名绑定的项目/环境 API_Key”。

  1. 进入「项目管理」页面，创建项目与环境。
  2. 在对应项目或环境中生成 API_Key（推荐优先使用环境级 Key）。(找管理员获取)
  3. 在「域名管理」中绑定域名到同一项目/环境，确保请求中的 domain 能解析到正确的密钥。
  4. 如果项目或环境已配置独立 API_Key，不能再使用公共默认 Key，否则服务端会返回 403。

适用范围：URL 刷新接口与文件上传外部 API 均共用这一获取方式。

1. URL 刷新接口：POST /api/refresh_url

接口： POST /api/refresh_url

Content-Type： application/json

字段 必填 说明
url(目录需以/结尾) 是 要刷新的 CDN 资源 URL
timestamp 是 Unix 秒级时间戳
signature 是 HMAC-SHA256 签名

签名规则

message = url + timestamp
signature = hmac.sha256(API_Key, message).hexdigest()

示例请求

curl -X POST https://cdn-manager.example.com/api/refresh_url \
  -H 'Content-Type: application/json' \
  -d '{
    "url": "https://cdn.example.com/assets/logo.png",
    "timestamp": 1720000000,
    "signature": "xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"
  }'

说明：

  • 请求中的 domain 必须绑定到已存在的项目/环境；签名使用解析后的项目/环境 API_Key。
  • API_Key 的获取方式见上方「公共说明：API_Key 获取」。
  • 服务器会记录本次 URL 刷新任务并返回刷新结果。

2. 文件上传外部 API 接入说明

客户端直接向对象存储上传，服务端只负责签发 PUT URL、校验和可选 CDN 刷新；上传与刷新使用相同的 HMAC 签名鉴权模式。

架构说明

┌─────────────┐    ① init / presign / complete     ┌──────────────┐
│  你的服务    │ ─────────────────────────────────► │ CDN Manager  │
└─────────────┘                                    └──────────────┘
       │                                                    │
       │  ② 返回预签名 PUT URL                               │ 解析域名 → 项目/环境 → 存储目标
       ▼                                                    ▼
┌─────────────┐    ③ PUT 文件（直传，不经 CDN Manager）   ┌──────────────┐
│  你的服务    │ ─────────────────────────────────► │  OSS/COS/OOS │
└─────────────┘                                    └──────────────┘
       │
       │  ④ complete + ETag
       ▼
┌─────────────┐                                    ┌──────────────┐
│ CDN Manager │ ── 可选 CDN 刷新 ────────────────► │  CDN 边缘节点 │
└─────────────┘                                    └──────────────┘
  • 文件不经过 CDN Manager 服务器转发，适合大文件与批量上传。
  • 鉴权与 URL 刷新接口一致，基于域名 + HMAC-SHA256。
  • 存储目标由域名绑定的项目 / 环境自动解析，无需在请求中传 Bucket 密钥。

鉴权规则

signature = HMAC-SHA256(API_Key, message).hexdigest()

# init
message = {domain}{timestamp}

# presign / complete
message = {domain}{job_id}{timestamp}

说明：timestamp 为 Unix 秒级时间戳，允许与服务器时差 ≤ 300 秒；若项目或环境已配置独立 Key，禁止再用公共默认 Key。

接口一览

方法 路径 说明
POST /api/upload/init 创建上传 Job，登记文件清单并批量签发小文件 PUT URL
POST /api/upload/presign 为未签发成功的小文件补签 PUT URL
POST /api/upload/complete 确认上传完成、服务端校验并可选触发 CDN 刷新

公共约定：Content-Type: application/json；JSON 响应中 success 表示执行结果，HTTP 4xx/5xx 时 body 可解析为错误对象。

1） 创建上传任务 — POST /api/upload/init

字段 类型 必填 说明
domain string 是 已绑定的 CDN 域名
timestamp int/string 是 Unix 秒
signature string 是 见签名说明中 init 消息拼接规则
files array 是 文件清单，元素包含 relative_path / size / mime
remote_prefix string 否 对象存储前缀，如 2026/09/，不要前导 /
storage_target_id string 否 指定存储目标；不传则用环境下第一个
refresh_after bool/int 否 为 true / 1 时，complete 成功后执行 CDN 刷新

文件对象字段：relative_path（相对路径，如 assets/app.js），size（字节数），mime（可选，默认 application/octet-stream）。首批最多 1000 个文件。

{
  "success": true,
  "job_id": "a1b2c3d4e5f67890",
  "domain": "cdn.example.com",
  "storage_target_id": "st_oss_prod",
  "files": [
    {
      "id": "f001abc123456789",
      "relative_path": "assets/logo.png",
      "size": 204800,
      "multipart": false
    }
  ],
  "presigned": [
    {
      "file_id": "f001abc123456789",
      "mode": "put",
      "upload_url": "https://bucket.oss-cn-hangzhou.aliyuncs.com/...",
      "method": "PUT"
    }
  ],
  "presign_errors": []
}

说明：单文件 ≤ 100MB 时自动签发 PUT URL；multipart: true 表示大文件，当前外部 API 不支持大文件分片。若未配置存储目标，接口会返回错误。

2） 补签 PUT URL — POST /api/upload/presign

字段 必填 说明
domain 是 同 init
job_id 是 init 返回的 Job ID
timestamp 是 Unix 秒
signature 是 按任务消息规则签名
file_ids 是 待补签文件 ID 列表，最多 50 个 
{
  "success": true,
  "files": [
    {
      "file_id": "f001abc123456789",
      "mode": "put",
      "upload_url": "https://...",
      "method": "PUT"
    }
  ],
  "errors": []
}

3） 直传对象存储

PUT {upload_url} HTTP/1.1
Content-Type: application/octet-stream
Content-Length: {size}

{文件二进制内容}
  • 必须使用 PUT，而不是 POST 表单上传。
  • 请求体大小必须与 init 中登记的 size 一致，否则 complete 校验失败。
  • 读取响应头中的 ETag，并去掉首尾双引号后上报给 complete。
  • 预签名 URL 有效期约 3600 秒，建议在过期前完成上传。

4） 完成上传 — POST /api/upload/complete

字段 必填 说明
domain 是 同 init
job_id 是 Job ID
file_id 是 文件 ID
timestamp 是 Unix 秒
signature 是 任务消息签名
etag 否 PUT 返回的 ETag；不传时服务端会自动 HEAD 获取 
{
  "success": true,
  "etag": "d41d8cd98f00b204e9800998ecf8427e",
  "public_url": "https://cdn.example.com/2026/09/assets/logo.png",
  "refresh": {
    "success": true,
    "refreshed": 1,
    "failed": 0,
    "results": [
      {
        "domain": "cdn.example.com",
        "url": "https://cdn.example.com/2026/09/assets/logo.png",
        "success": true
      }
    ]
  }
}

5）完整流程示例（Python）

import hashlib
import hmac
import json
import time
import urllib.request

BASE = "https://cdn-manager.example.com"
DOMAIN = "cdn.example.com"
API_SECRET = "your-environment-or-project-api-key"


def sign_init(domain: str):
    ts = int(time.time())
    message = f"{domain}{ts}"
    sig = hmac.new(API_SECRET.encode(), message.encode(), hashlib.sha256).hexdigest()
    return ts, sig


def sign_job(domain: str, job_id: str):
    ts = int(time.time())
    message = f"{domain}{job_id}{ts}"
    sig = hmac.new(API_SECRET.encode(), message.encode(), hashlib.sha256).hexdigest()
    return ts, sig


def post(path: str, payload: dict) -> dict:
    req = urllib.request.Request(
        f"{BASE}{path}",
        data=json.dumps(payload).encode(),
        headers={"Content-Type": "application/json"},
        method="POST",
    )
    with urllib.request.urlopen(req, timeout=60) as resp:
        return json.load(resp)


def upload_file(local_path: str, remote_path: str, refresh: bool = True) -> dict:
    with open(local_path, "rb") as f:
        f.seek(0, 2)
        size = f.tell()

    ts, sig = sign_init(DOMAIN)
    init_body = {
        "domain": DOMAIN,
        "timestamp": ts,
        "signature": sig,
        "remote_prefix": "2026/09/",
        "refresh_after": refresh,
        "files": [
            {"relative_path": remote_path, "size": size, "mime": "application/octet-stream"}
        ],
    }
    init = post("/api/upload/init", init_body)
    if not init.get("success"):
        raise RuntimeError(init.get("error"))

    job_id = init["job_id"]
    file_id = init["files"][0]["id"]
    presigned = init.get("presigned") or []

    if not presigned:
        ts2, sig2 = sign_job(DOMAIN, job_id)
        presign = post("/api/upload/presign", {
            "domain": DOMAIN,
            "job_id": job_id,
            "timestamp": ts2,
            "signature": sig2,
            "file_ids": [file_id],
        })
        presigned = presign.get("files") or []

    upload_url = presigned[0]["upload_url"]
    with open(local_path, "rb") as f:
        data = f.read()
    put_req = urllib.request.Request(upload_url, data=data, method="PUT")
    with urllib.request.urlopen(put_req, timeout=300) as put_resp:
        etag = put_resp.headers.get("ETag", "").strip('"')

    ts3, sig3 = sign_job(DOMAIN, job_id)
    return post("/api/upload/complete", {
        "domain": DOMAIN,
        "job_id": job_id,
        "file_id": file_id,
        "timestamp": ts3,
        "signature": sig3,
        "etag": etag,
    })


if __name__ == "__main__":
    result = upload_file("./logo.png", "assets/logo.png")
    print(json.dumps(result, ensure_ascii=False, indent=2))

cURL 示例

init

TS=$(date +%s)
DOMAIN="cdn.example.com"
SECRET="your-api-key"
MSG="${DOMAIN}${TS}"
SIG=$(printf '%s' "$MSG" | openssl dgst -sha256 -hmac "$SECRET" | awk '{print $2}')

curl -sS -X POST "https://cdn-manager.example.com/api/upload/init" \
  -H "Content-Type: application/json" \
  -d "{
    \"domain\": \"$DOMAIN\",
    \"timestamp\": $TS,
    \"signature\": \"$SIG\",
    \"remote_prefix\": \"2026/09/\",
    \"refresh_after\": true,
    \"files\": [{\"relative_path\": \"test/hello.txt\", \"size\": 12}]
  }"

PUT（将 {upload_url} 替换为上一步返回值）

curl -sS -X PUT "{upload_url}" \
  -H "Content-Type: application/octet-stream" \
  --data-binary "hello world!"
# 记录响应头 ETag

complete

JOB_ID="..."
FILE_ID="..."
ETAG="..."
TS=$(date +%s)
MSG="${DOMAIN}${JOB_ID}${TS}"
SIG=$(printf '%s' "$MSG" | openssl dgst -sha256 -hmac "$SECRET" | awk '{print $2}')

curl -sS -X POST "https://cdn-manager.example.com/api/upload/complete" \
  -H "Content-Type: application/json" \
  -d "{
    \"domain\": \"$DOMAIN\",
    \"job_id\": \"$JOB_ID\",
    \"file_id\": \"$FILE_ID\",
    \"timestamp\": $TS,
    \"signature\": \"$SIG\",
    \"etag\": \"$ETAG\"
  }"

限制与约定

项目 值
单批 init 文件数 1000
单次 presign 文件数 50
单文件 PUT 上限 100 MB
预签名 URL 有效期 3600 秒
时间戳有效窗口 ±300 秒
  • 大文件（> 100MB）暂不支持外部 API 分片上传，需在后台文件存储页上传或拆分为小文件。
  • 外部 API 不提供 Job 进度查询，需自行跟踪 job_id 与 file_id。
  • 若域名没有绑定项目/环境或存储目标，complete 可能成功但 refresh 失败，public_url 也可能为空。
